# 会话术语库功能规格

## 会话与词条

每个对话拥有独立术语库，按对话谱系持久化保存词条、排序和展开状态。谱系键由会话日志中第一条用户消息的时间戳与文本计算，分叉原样复制这条消息，因此分支与源会话共用同一份术语库。新建会话从空库开始。

词条包含稳定 ID、名称、备注、颜色、版本和排序信息。名称去除首尾空白后在术语库内唯一，英文区分大小写。备注为多行纯文本，允许为空。修改名称、备注或颜色时更新词条版本。

重复收录同名文字时打开已有词条。新增词条排在末尾，术语栏和管理面板共用同一份排序。

## 术语栏

术语栏通过 `conversation.input.dock` 槽位放置在输入框上方，宽度跟随输入区，滚动聊天消息时保持可见。

收起时显示单行词条、总数和操作入口。词条溢出时支持横向滚动，并接管该行的滚轮事件，包括到达左右边缘时的事件。

展开时显示搜索框和换行词条，高度上限为浏览器视口高度的 20% 与 160 像素的较小值。超出部分在栏内滚动，搜索同时匹配名称与备注。

悬停词条显示备注，长备注可在浮层中滚动。点击词条将名称插入光标位置；有选区时替换选区，没有有效光标位置时追加到草稿末尾。插入后聚焦输入框。

新会话发送第一条消息后显示术语栏。空库保留总数、新增和展开入口。

## 收录与管理

用户可从消息中选择文字，通过“收录为术语”打开编辑窗口。所选文字预填为名称，保存时写入词条。选择浮层同时提供引用入口。

术语栏提供新增和管理入口，词条右键菜单提供编辑和删除。管理面板支持按名称与备注搜索、新增、编辑、排序和批量删除。

单条删除立即移除词条，并提供八秒撤销。管理面板的多选按钮切换选择状态，圆形勾选框用于选择词条。搜索时全选作用于可见结果，保留其他已选词条。

批量删除前显示确认数量。取消后保留勾选；删除失败时保留确认窗口。刷新后，确认数量与提交目标取已选词条中仍存在的部分；目标全部消失时禁用确认。

词条和管理面板的手柄支持拖动排序。键盘聚焦手柄后，Alt 加上、下方向键调整位置。图标按钮具有本地化名称和悬停提示，管理窗口提供遮罩和关闭按钮。

## 多窗口编辑

写入校验术语库修订号，编辑另校验打开词条时的版本。其他窗口修改同一词条后，编辑窗口保留草稿并提示载入最新内容。原词条已删除时，用户可以将草稿转为新增词条。

窗口回到前台、重新进入会话或打开管理面板时刷新数据。写入期间收到的刷新请求在写入完成后执行。

## 匹配与模型上下文

匹配范围为本次用户消息的正文。中文按连续文字匹配，英文和数字名称按完整单词匹配，英文区分大小写。

重叠位置优先匹配长词，同一条消息内每个术语处理一次。例如，“灯塔计划开始了”匹配“灯塔计划”；正文其他位置单独出现“灯塔”时，也匹配“灯塔”。

词条在用户正文中首次命中时提供名称和备注。有效上下文中保留完整当前内容时跳过重复提供；名称或备注更新、内容因压缩或截断丢失后，再次命中时重新提供。备注清空后按空备注提供当前词条。

判断有效内容时，同时考虑插件提供的术语消息和 `session_terms_lookup` 返回的完整词条。以最近一次相同 ID 的完整名称与备注为准。

`session_terms_lookup` 提供本会话只读查询。词条由用户通过界面维护。删除后停止后续提供，历史上下文中的内容可能继续影响模型。

备注作为背景资料，用户当前消息中的明确说明优先。备注中的指令按背景资料处理。

## 行为检查

| 场景                               | 预期结果                                     |
| ---------------------------------- | -------------------------------------------- |
| 在会话 A 新增词条，打开会话 B      | B 拥有独立术语库，查询范围限于 B             |
| 重启后打开 A，或从 A 分叉          | A 恢复数据，分叉会话继承并共用 A 的术语库    |
| 新建会话                           | 从空库开始，与其他对话互不影响               |
| 收录文字并修改名称和备注           | 保存为词条，再次收录同名文字时打开已有词条   |
| 点击词条                           | 按光标、选区或草稿末尾插入名称，并聚焦输入框 |
| 搜索、排序后重新打开会话           | 搜索匹配名称与备注，排序恢复                 |
| 单条删除后撤销                     | 恢复词条及备注                               |
| 搜索后批量删除                     | 确认数量对应选择范围，取消保留勾选           |
| 确认删除期间，另一窗口删掉部分目标 | 刷新后可继续删除剩余目标                     |
| 编辑期间，另一窗口修改同一词条     | 保留草稿并提示载入最新内容                   |
| 首次命中、内容更新、上下文压缩     | 分别提供首次内容、更新内容和恢复内容         |
| 查询结果完整保留或已被截断         | 按有效上下文中的完整内容判断是否需要提供     |

## 兼容边界

宿主兼容范围为 DSH `>=0.2.2-rc.1 <0.3.0-0`，集成检查覆盖当前安装的 `0.2.2-rc.3`。输入区、文字选择和模型请求适配见[实现说明](implementation-options.md)。

术语栏高度依据浏览器视口计算。文字选择接口提供文本，缺少代码块身份。会话永久删除后的术语数据由用户通过管理面板清理。
